# yaya

Base de connaissances SIXT : documents sources dans `docs/sixt/`, site statique généré dans `site/`.

## Site

- Régénérer : `pip install markdown && python3 scripts/build_site.py`
- Ouvrir `site/SIXT_site.html` (version en un seul fichier, à double-cliquer) ou `site/index.html`. Publier le dossier `site/` pour le mettre en ligne (GitHub Pages, Netlify…).
- Fonctions : navigation, sommaire par page, recherche plein texte, badges de fiabilité, impression.

Voir `CLAUDE.md` pour les règles de contenu.
